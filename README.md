# Freelancing Marketplace Platform – Week 2

A professional and responsive freelancing marketplace platform developed as part of my **Internship Week 2 Task**.

---

## 📌 Project Overview

The Week 2 task focused on transforming the initial marketplace landing page into a more interactive freelancing platform by implementing marketplace functionality, service discovery features, freelancer profiles, and service details pages.

---

## 🚀 Features

* Freelancer marketplace page
* Search freelancers and services
* Category-based filtering system
* Service sorting functionality
* Freelancer profile pages
* Service details pages
* Dynamic profile navigation
* Local Storage data handling
* Favorite freelancer/service functionality
* Login and Register modals
* Toast notification system
* Responsive mobile navigation
* Interactive UI components
* Fully responsive design

---

## 🛠 Technologies Used

* HTML5
* CSS3
* JavaScript
* Local Storage API
* Font Awesome
* Google Fonts
